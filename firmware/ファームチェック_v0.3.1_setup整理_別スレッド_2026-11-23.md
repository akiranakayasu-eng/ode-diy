## 結論

**高 0・中 0・低 4。** PIN を外した API は 3 つとも、本体ボタン（SW2 の 3 秒長押し）で開く窓で守られている。ほかに PIN も窓も無しで書き換えられる所は増えていない。

## PIN を外した API が窓で守られているか

| API | PIN | 窓のチェック | 試験版で窓が閉じているとき | 窓が開いているとき |
|---|---|---|---|---|
| `POST /api/ui`（差し替え） | 不要 | `upload_start`（http.c:556）で窓が閉じていれば本文を読み捨てて 403 | 403 `{"ok":false,"error":"button"}` | 200 `ok:true` |
| `POST /api/ui/reset`（内蔵の画面に戻す） | 不要 | http.c:494 | 403 button | 200 `ok:true` |
| `POST /api/dfu`（ファーム更新モード） | 不要（v0.3.1 から） | http.c:487 | 403 button（`?pin=1234` を付けても同じ） | 200 `ok:true,"mode":"dfu"` |
| `POST /api/settings`（PIN と、画面に出ない設定） | 要る | なし（PIN で守る） | — | — |

- 窓の判定は `app_ui_window_left_s()` だけで、開けるのは `main.c` の SW2 の 3 秒長押し（試験版は標準入力の `l`）だけ。HTTP や WebSocket から窓を開ける道は無い（http.c と app.c を grep で確認）。
- 窓が閉じているとき、/setup のアップロード・戻す・ファーム更新のボタンは押せない（`disabled`）。押せなくしているのは画面の側だけだが、サーバ側でも上のとおり断る。

## そのほかに確かめたこと

- **hex がこのソースから作られているか:** ビルドし直すと、置いてある bin との違いはビルド時刻の 2 バイトだけだった。hex を bin に直すと置いてある bin と一致した。コンパイラの新しい警告は出ていない（newlib の `_close` などの決まった警告だけ）。
- **画面:** `setup_v0.3.1.png` と `setup_page.h` を照らし合わせた。上から順に「画面（miseru）の差し替え（窓の状態を緑・灰の帯で表示、いまの画面、開く URL）」「PIN（miseru の Admin 用）」「ファームの更新（たたんである）」の 3 つで、ネットワーク・名前などの欄は無い。依頼の「PIN は Admin のみ」「不要なものは外す」に合っている。成功の文は青（`.ok{color:#0645ad}`）、失敗は赤。
- 名前・IP・MAC は `textContent` で入れているので、名前に `<` などが入っても HTML として読まれない。

## 指摘

### 低

1. **ファーム更新モードに入れる人が増えた。** 窓が開いている 10 分のあいだは、LAN の誰でも（または、そのとき 作者のブラウザが開いたほかのサイトのページからでも）`POST /api/dfu` 1 回で LAN と DMX の出力を止められる。止まった状態は電源を入れ直すまで続く。v0.3.0 までは PIN がその歯止めになっていた。作者の決定（PIN は Admin のみ）どおりで、窓が要るので低とした。前々回の低 4（窓は使ったあとも 10 分開いたまま）と合わせると、差し替えが済んだら窓を閉じる形にすれば、この心配も小さくなる。
2. **README の表の行が古いまま。** `README.md:34`（ファームの更新の行）は「v0.3.0 から…10 分の間だけ、PIN も要る」のまま。末尾の API の書き方だけ `POST /api/dfu`（v0.3.0 は `?pin=`）に直っている。11 行目と 56 行目は直っている。
3. **「もう一度押してください」があいまいに戻った。** `setup_page.h` の NB の文が「SW2 を 3 秒押し続けてから、もう一度押してください」になった。前々回に「この画面のボタンをもう一度押してください」と直した所が、作り直しで元に戻っている。ボタンは窓が閉じていると押せないので、この文が出るのは、5 秒ごとの読み込みの合間に窓が閉じたときだけ。
4. **PIN で今も画面に出ない設定を変えられる。** `POST /api/settings` は PIN があれば IP・許可リスト・名前なども変えられる（前回までの低 1 と同じ、変わっていない）。画面の見出しは「PIN（miseru の Admin 用）」なので、知らない人が「PIN は Admin だけに効く」と受け取ってもおかしくない。README には書いてある。
