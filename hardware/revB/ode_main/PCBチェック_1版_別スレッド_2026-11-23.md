## 中（発注前に直したい）

### 中 1　ESP32-S3 モジュールが後ろの辺の中央にある（アンテナの給電点が基板の角にない）

- 今: U1 は (38.0, 77.25)、180 度。モジュールの側端は x = 29.0 と 47.0 で、左の辺から 29mm、右の辺から 29mm。アンテナ部 6mm は y = 84〜90 で基板の外（推奨ランドの 7.49mm と 1 番パッドの位置から確認、基板の端はアンテナ部の境目とちょうど同じ）。
- 出典: 設計ガイド 1.4.7。「feed point of the antenna close to the edge of the base board」。図 24・図 25 では、辺の中央に置いた 2 番は ✓ が無く「not recommended」、✓ は給電点が角に来る置き方（図 24 の 3・4、図 25 の 1・5）。図 26 は給電点側の基板の端をモジュールの側端から「Max 2」mm 以内にしている。
- 給電点がモジュールのどちら側か: 図 26 は「Antenna feed point on the right」。モジュールのデータシートの図 3 には給電点の記載が無く、WROOM-1 がどちらかはデータシートで確かめられなかった（**未確認**）。図 26 と同じ右（40 番ピン側）なら、この基板では 40 番ピン側は x = 29 の左側なので、**左後ろの角**（モジュールの左端を基板の左の辺から 2mm 以内）に寄せる形になる。
- 案: U1 を後ろの角へ動かす（U6・J4・R80/R81・C74/C75 の場所が変わる）。動かせない場合は、実機で通信距離とスループットを確かめる前提で今の位置にする（ガイドも最後は実機での確認を求めている）。

### 中 2　USB の 5V から LDO までの電流が 0.2mm の線と 1 本ずつのビアを直列に通る

- 今（電流の通る順）: J1 VBUS → F.Cu 0.2mm → ビア (6.5, 9.25)／(8.25, 9.75) → **B.Cu 0.2mm 約 11mm** → ビア (6.0, 20.5) → F1 → 0.5mm → C1 → **F.Cu 0.2mm 2.4mm** → Q1.2 → Q1.3 → **0.2mm** → ビア (6.0, 30.0) → **B.Cu 0.2mm 約 7mm** → ビア (6.0, 36.75) → C3 → B.Cu 0.5mm → ビア (6.0, 51.0) → U6・U11。VBUS・VBUS_F・+5V にベタは無い。
- 5V の電流（自分で見積もり）: 3.3V 側は ESP32-S3-WROOM-1 の送信ピーク 355mA（モジュール DS 表 12、802.11b 20.5dBm）＋ W5500 132mA（W5500 DS 5.4、100M 送信）＋ LED 約 20mA ＝ 約 0.51A。これに ADM2587E の 5V 電流（DS が読めず **未確認**、仮に 0.2A）を足して、**ピークで約 0.7A**。平均は Wi-Fi 受信中心なら 0.3〜0.45A 程度。
- 許容の目安（IPC-2221 の式。外層 1oz 35µm、ビアのめっき 18µm と仮定、めっき厚は JLCPCB の値を読めず **未確認**）:
  - 0.2mm 外層線: 温度上昇 10℃で約 0.74A、20℃で約 1.0A
  - 0.5mm 外層線: 10℃で約 1.45A
  - ビア 0.3mm 穴: 内層の式で 10℃で約 0.71A、20℃で約 0.96A
- ピーク 0.7A に対して、0.2mm 線とビア 1 本はちょうど 10℃上昇の目安くらいで余裕が無い。Wi-Fi のピークは短いので実際の発熱は小さいと見られるが、入口の線を細くしておく理由も無い。
- 案: VBUS・VBUS_F・+5V の電流の通る所を 0.5mm 以上（できれば F.Cu のベタ）にし、層を移る所はビアを 2〜3 本にする。下の「電源ネットのビア一覧」も参照。

### 中 3　U6（LDO）の出力が 0.2mm の線とビア 1 本で +3V3 の面へつながり、出力コンデンサ C5 と表の銅でつながっていない

- 今: U6.3（5.85, 59.3）→ F.Cu 0.2mm 約 1.5mm → ビア (4.40, 59.30) → In2（+3V3 の面）。C5 10µF（5.5, 63.5）は自分のビア (3.94, 65.30) で In2 に落ちるだけで、U6.3 とは表で直接つながっていない。3.3V の全電流（ピーク約 0.51A）がこの 1 本のビアを通る（ビア 1 本の目安 0.71A／10℃）。
- 出力コンデンサと LDO の出力ピンの間にビア 2 本と面が入るので、出力ピンから見たコンデンサの配線インダクタンスが増える。MCP1826 の出力コンデンサの置き方の条件は DS が読めず **未確認**だが、一般には出力ピンのすぐそばに置く。
- 案: U6.3 と C5.1 を表の太い銅（ベタ）で直結し、+3V3 の面へのビアを 3 本以上にする。C4（入力 100n）・C3（入力 22µ）も同様に U6.1 の近くで表の銅で直結する（今は C4 は 0.5mm 線でつながっている）。

### 中 4　U6 の放熱の銅が無い

- 今: U6 のタブ（GND、2.0 × 3.8mm のパッド）は、パッドだけでベタが無く、In1（GND の面）へのビアはタブに 1 本 (12.15, 59.35)。F.Cu・B.Cu には絶縁側以外の GND ベタが無い。
- 損失（自分で見積もり）: (5.0 − 3.3)V × 0.51A ＝ ピーク約 0.85W、平均（0.25〜0.3A）で約 0.45W。MCP1826 の SOT-223 の熱抵抗は DS が読めず **未確認**。SOT-223 でパッドだけなら熱抵抗は大きく（数十〜百 ℃/W 台）、ケースの中では 100℃前後に届きうる。
- 案: タブの周りの F.Cu に GND のベタを広く取り、タブの下と周りにビアを 6〜9 本打って In1 と B.Cu のベタへ逃がす。それでも足りなければ降圧に替える。
- U1 は U6 から約 20mm 離れている（N16R8 は使用温度の上限が低いので、U6 の熱が U1 に回らない配置は良い）。

### 中 5　W5500 の TOCAP のコンデンサ C54 が遠い

- 出典: W5500 DS ピン表 20 番 TOCAP「This pin must be connected to a 4.7uF capacitor. The trace length to capacitor should be short to stabilize the internal signals.」
- 今: C54 4.7µ（20.76, 39.3）は U3.20（24.84, 33.75）から約 6.9mm。ネット /TOCAP の線は合計 15.5mm、ビア 2 本（表 → 裏 → 表）。
- 案: C54 を 20 番ピンのすぐ横（または C58〜C60 と同じく裏の直下）に置き、ビアを使わずに短くつなぐ。

## 低

1. **W5500 の水晶 Y2 が遠く、XO 側が回り道**: Y2 (25.0, 44.0) から U3.30/31 まで約 7mm。/X25_IN 12.8mm、XO 側は /X25_OUT 17.2mm ＋ R62 ＋ /X25_XO 10.0mm（ビア 4 本）で合計約 27mm。C52 は Y2 から約 4mm。W5500 DS 図 3 は回路だけで配置の決まりは無いが、線の浮遊容量で負荷が変わる。Y2・C51・C52・R62 を U3 の 30・31 番の近くへ寄せ、XO の線からビアを無くしたい。
2. **Ethernet の対の長さの差とビアの数の差**: RXP 19.0mm（ビア 2）／RXN 12.2mm（ビア 0）、RDP 16.5mm（ビア 2）／RDN 10.0mm（ビア 1）、TXP 11.8／TXN 9.8mm。差 6.5〜6.8mm は 100BASE-TX の 1 ビット 8ns に比べて約 45ps で、動作への影響は小さいと見る。対ごとにビアの数をそろえ、差を数 mm 以内にするとよい。
3. **USB D+／D− が長く、ビアが多い**: /USB_DP 107.2mm（ビア 4）、/USB_DM 108.0mm（ビア 5）。設計ガイド 1.4.8 は「90Ω の差動、等長、ビアは最少、ビアには GND のリターンビアを 1 対、下に連続した GND の面」。B.Cu を通る所は隣が In2（+3V3）で GND ではない。ESP32-S3 の USB はフルスピード（12Mbps）なので動作上の余裕は大きいが、J1 と U1 の距離を縮めるか、B.Cu の区間を減らしたい。R4・R5（0Ω）と C76・C77 は U1 の近く（約 3mm）で、ガイドの「chip side」に合っている。U5（USBLC6）は J1 のそば。
4. **外層に GND ベタが無い**: F.Cu・B.Cu のベタは絶縁側（GND_ISO_1・GND2_PWR_1）だけ。設計ガイド 1.4.6（UART の線を GND の銅とビアで囲む）、1.4.7（アンテナの近くに十分な GND の銅と密なビア）、1.4.8（USB の線を GND の銅で囲む）。一次側の外層に GND ベタを入れ、後ろの辺のアンテナ寄りにビアを並べたい（中 4 の放熱にも効く）。
5. **アンテナの近くにコネクタ**: J4（UART、x = 11〜20, y = 81.5）はモジュールの左端から約 9mm、J6（天板 8P、x = 53〜71, y = 72.5）は右端から約 6mm。設計ガイド 1.4.6 前後「USB port, USB-to-serial chip, UART signal lines (... header pins ...) must be as far away from the antenna as possible」。J6 のケーブルは天板へ立ち上がるのでアンテナの近くを通りうる。中 1 で U1 を動かすときに、J4・J6 をアンテナから離す向きに置き直したい。
6. **絶縁帯の最小は C109 の 1.8mm**: 測った最小間隔（絶縁側の銅と一次側の銅）は、In1・In2 で 7.75mm、B.Cu で 8.03mm、U11 のパッド列の間で 7.25mm、C109（1n/2kV、1206）のパッドの間で 1.8mm（その線どうしで 2.63mm）。C109 は帯をまたぐ意図の部品で rev A と同じ。シルクの「ISOLATION 2.5kV」は、C109 の定格 2kV と 1.8mm の沿面より強い表記に読める。表記を「ISO」程度にするか、帯をまたぐのに沿面の長い安全規格品（Y コンデンサ）を使うか。ADM2587E 自体の沿面・空間距離は DS が読めず **未確認**。
7. **シルク**: 文字の高さ 0.8mm・線 0.15mm、部品の外形線 0.12mm。JLCPCB の推奨（文字の高さ 1mm 以上、線 0.15mm 以上と記憶しているが **未確認**）に届かない所がある。「ANTENNA ->」の矢印は右（+x）を向いているが、アンテナは後ろの辺（+y）の外にある。「Art-Net」は Artistic Licence の商標（シルクに載せるなら「Art-Net™ Designed by and Copyright Artistic Licence」の表記が要るか確かめたい）。
8. **W5500 の 1V2O の C53 と AVDD のパスコン**: C53 10n は U3.22 から約 4.7mm、/1V2O の線 15.2mm・ビア 2（DS は「must be connected to a 10nF capacitor」で長さの注記は無い）。AVDD の C60 は 7.3mm、C54 以外の C53〜C57 も 4〜7mm。裏の直下（C58〜C60 と同じ）にまとめると短くなる。
9. **天板の LED の電流が色で大きく変わる**: 本体の R84〜R86 100Ω ＋天板の R2〜R4 680Ω ＝ 780Ω。ESP32-S3 の出力は VOH ≥ 0.8 × VDD（モジュール DS 表 9）。赤・黄（VF 約 2.0V）なら約 1.6mA、青・白（VF 約 2.8〜3.0V）なら 0.4〜0.6mA で暗い。LED の型番と VF を決めてから R2〜R4 を決める（天板の README で未定と書かれている点）。
10. **J6 の 1 番で +3V3 がそのまま基板の外へ出る**: ケーブルや天板の短絡で 3.3V の系統全体が落ちる（ESP32 と W5500 も止まる）。天板では D1 PWR の約 2mA だけなので、本体側に直列抵抗（例: D1 の電流制限を本体で持つ）を入れると守れる。
11. **天板の LOCK ボタンのプルアップが内部だけ**: IO7 の内部プルアップは 45kΩ（モジュール DS 表 9、RPU）。ケーブルの先のスイッチを 45kΩ と C78 100n で受けるので、立ち上がりは約 4.5ms と遅く、ノイズにも弱め。本体に 10k の外部プルアップを置くと安定する（R83 1k・C78 の働きは変わらない）。

## 回路図 5 版の変更（R83・C78・R84〜R86）

- J6.4 BTN_LOCK → R83 1k → BTN_LOCK_M（C78 100n → GND）→ U1.7（IO7）。J6.5〜7 → R84〜R86 100Ω → U1.4〜6（IO4〜IO6）。PDF の絵とネットリストと PCB のパッドのネットが一致。
- IO4〜IO7 はストラップピンではない（モジュール DS 3.3: ストラップは GPIO0・GPIO46・GPIO45・GPIO3）。R84〜R86 が入っても電源投入時の動きには関係しない。

## 問題なしと確かめた点

- **U1 のランド**: 40 パッド 1.5 × 0.9mm、ピッチ 1.27mm、左右の列の中心間 17.5mm、1 番パッドがモジュールの端から 7.49mm、EP は 0.9mm 角 9 個（3.7mm 角）でビアはすき間に置く形。モジュール DS 図 10 と一致。EP のビアはテンティングあり、ペーストは 9 個の角だけ。
- **U1 のピンとネット**: 3 EN、13 IO19＝USB D−、14 IO20＝USB D+、27 IO0＝BOOT、36 RXD0、37 TXD0、4〜7 IO4〜7（LED・LOCK）、10 IO17＝TX_U、11 IO18＝STAT、17〜23 IO9〜IO14・IO21（W5500 と DE）。モジュール DS 図 3 と一致。IO35〜37（PSRAM）は未接続。
- **U1 の 3V3 のパスコン**: C31 22µ が 2.3mm、C32 100n が 3.2mm（モジュール DS 図 7 の 22µF ＋ 0.1µF）。
- **U3 W5500 のピンとネット**: 1 TXN、2 TXP、5 RXN、6 RXP、10 EXRES1（R61 12.4k 1% が裏の直下）、20 TOCAP、22 1V2O、23 GND、30 XI、31 XO、32〜36 SPI・INT、37 RST、43〜45 PMODE 未接続（内部プルアップで全機能の自動ネゴ）。DS のピン表と一致。
