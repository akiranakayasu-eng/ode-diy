## PCB 4 版のチェックで残した点（低 3、どれも直さずに残した）

1. 裏の MISO が W5500 の水晶の真下を通る。間に内層の GND と +3V3 があるので影響は小さい。
2. SCLK の直列抵抗 R76 が W5500 側にある。ダンピングの抵抗なら ESP32 側が良い。今は 0Ω なので実害はない。必要になったら次の版で寄せる。
3. UART の 2 本がモジュールの下をアンテナと平行に約 16mm 通る。ログ用で低速なので、そのままにした。

## PCB 1 版（2026-11-23、作ったスレッドでの確認まで）

- 76 × 84mm、4 層 FR-4 1.6mm（F.Cu・B.Cu 信号、In1 GND、In2 +3V3）。前の辺に左から USB-C J1、RJ45 J5、XLR3 J11（rev A の左 76mm と同じ位置）。ポート 1 の絶縁の島と帯も rev A と同じ寸法
- U1 ESP32-S3-WROOM-1 は後ろの辺に 180 度で置き、アンテナ部 6mm を基板の外へ出した（ESP32-S3 ハードウェア設計ガイド）
- W5500 U3 は RJ45 の後ろ。1〜12 番（TX/RX）を RJ45 側、水晶と SPI を U1 側に向けた
- U6（LDO）は左の後ろ、F1 は左の前（36mm 離した。docs/電流の見積もり_revB.md）
- 取り付け穴 M3 は (3.5, 45)・(72.5, 58)・(3.5, 80.5)・(72.5, 80.5)（基板の左上が原点、mm）。前の 2 つはコネクタと絶縁の島を避けて後ろへずらした。天板と底板もこれに合わせる
- 自動配線（scripts/route.py、rev A と同じ A*）で未配線 0。DRC はエラー 0、警告 5（U1 と J11 のシルクが基板の端で切れる 4、U1 の EP のビア穴を 0.2→0.3mm にしたためのライブラリとの差 1）
- verify_pcb.txt: パッドのネット照合、ベタのパッドのビア、パスコンの距離、SMD パッドの中のビア 0
- 気になる点（チェックで見てほしい）: Ethernet の対の長さの差（RXP 19.0mm／RXN 12.2mm、RDP 16.5mm／RDN 10.0mm）、USB D+／D− が約 108mm（J1 が左前、U1 の USB ピンが右側のため）、U6 の放熱の銅（まだ広げていない）
- 作り直し: docker kicad/kicad:10.0 の中で `sh scripts/all.sh`（geom → 配線 → 基板 → DRC → 照合）。絵は `bash scripts/render.sh`

## 残っている確認

1. 3.3V の合計電流と U6 の発熱（見積もりは docs/電流の見積もり_revB.md）（ESP32-S3 ピーク 355mA ＋ W5500 約 128mA ＋ LED。5V→3.3V で 1W 近くになりうる）。PCB で放熱の銅を取るか、降圧に替えるか。
2. RJMG1BD3B8K1ANR のトランス仕様（巻数比・インダクタンス）を Amphenol の図面で確かめる（作業環境から読めない）。
3. 天板の基板の回路図は ../ode_top_revB（2026-11-23）。天板の PCB はまだ。
4. F1 の保持電流は 25℃ 1.1A、60℃ 0.8A（秋月 113955 の表、4 版チェックで確認）。5V の合計電流（U6 の 3.3V 側、U11 ADM2587E、U7・U9）を出し、PCB で F1 を LDO から離して置くか、保持電流が上の品にするかを決める。
