## 指摘

### 高

なし。

### 中

なし。

### 低

**低 1. USB の C76・C77（DNP）が 0Ω の R4・R5 のチップ側にあり、Espressif の図ではコネクタ側。**（3 版で新しく出た）
- [H] USB の図（ESP32-S3 USB RC Schematic）: R13・R14（22/33Ω）は「chip side」から J1 へ向かって入り、C32・C33（NC）は R13・R14 と J1 の間、つまりコネクタ側。[E] 図 7 も R4・R6（0）の USB コネクタ（JP3）側に C5・C6（TBD）。
- 3 版: C76 は USB_DP_M（R4 と U1.14 の間）、C77 は USB_DM_M（R5 と U1.13 の間）でチップ側。
- [H] の文は「reserve series resistors … and capacitors to ground on the traces …, and place them close to the chip」で、抵抗とコンデンサの順番は文では決めていない。図に合わせるなら C76・C77 を USB_DP・USB_DM（R4・R5 と U5 の間）へ移す。R4・R5 が 0Ω で C76・C77 が未実装のあいだは回路は同じ。値を入れて調整するときに図と順番が違う、という点だけ。
- ついでに: [H] は直列抵抗の初期値を 22/33Ω としている。[E] 図 7 は 0。3 版の 0Ω はモジュールの図どおりで、問題とはしない。

**低 2. CC の ADC のコンデンサ C74・C75 が 10nF で、[H] の推奨 0.1µF より小さい。**（3 版で新しく出た）
- [H] ADC:「Please add a 0.1 μF filter capacitor between ESP pins and ground when using the ADC function to improve accuracy.」
- 3 版は 10nF。22k の後ろなので、CC 線から見た容量の心配（0.1µF を CC に直接付けられない理由）はもう無い。0.1µF にしても時定数は 22k × 0.1µF ＝ 2.2ms で、CC の電圧はつないだときと充電器の電流の表示が変わるときにしか動かないので、読みに差し支えない見込み。
- 10nF でも ADC が読めないわけではない。どれだけ精度が落ちるかは ESP32-S3 の ADC の入力（サンプリング容量）の数値が出典に無く、未確認。[H] どおりにするなら C74・C75 を 0.1µF にする。
- 確かめた数字（参考）: [H] の ATTEN=3 の範囲は 0〜2900mV（誤差 ±50mV）、ATTEN=2 は 0〜1600mV（±10mV）。Type-C の Rd 側に出る電圧の範囲（Default・1.5A・3A の判定のしきい値）は USB Type-C の規格の数値で、今回の出典に無いので未確認。どの ATTEN で読むかはファームで決める。

**低 3. PDF で J6 の 2 番の GND 記号が 3 番・4 番のラベルと重なっている。**（3 版で変えた所のそば、見た目だけ）
- ode_main_revB.pdf を 300dpi で見ると、J6.2 の GND 記号と「GND」の文字が「EN_PANEL」「BTN_LOCK」の文字に重なる。ネットリストは J6.2 GND・J6.3 EN_PANEL・J6.4 BTN_LOCK で正しい。2 版の J4 と同じ種類の重なり。

## 問題なしと確かめた所（変えた所とそのまわり）

- 3 版で足した部品はどれも 2 端子が別々のネットにつながり、片側だけ浮いている部品は無い。C76・C77 の値は DNP。
- 部品のフットプリントは R80・R81・R82 が R_0805、C74〜C77 が C_0805 で、ほかの抵抗・コンデンサと同じ。
- IO1・IO2 のリセット中・リセット後は [H] IO Pin Default Configuration で「IE」（入力、プルなし）。外の 22k と Rd 5.1k を引っぱらない。
- 電源投入時のグリッチ: [H] で GPIO1・GPIO2 は Low 60µs。そのあいだ C74・C75 は 0V に引かれ、CC から見ると Rd 5.1k に 22k が並ぶ（5.1k ∥ 22k ≈ 4.1k）。終わったあとは 22k を通して C74・C75 が充電される（約 0.2〜0.3ms）。どちらも短い。充電器が切断と見なす時間・電圧のしきい値は Type-C 規格の数値で、出典に無く未確認（2 版の中 1 で直結だったときより影響は小さい）。
- ESP32 に電源が入る前に CC に電圧がかかっても、ピンへ流れる電流は 22k で絞られる。
- IO17 の Low グリッチ（[H] 60µs）は R82 0Ω の前後で変わらない。そのあいだ DE（IO21）は R74 で Low（[H] で GPIO21 はグリッチの表に無い）なので、DMX 線には出ない。
- ERC 0（erc.rpt、2026-11-19 01:31）。
- 回路図の注記「R80/R81 22k + C74/C75 10n: CC to ADC through series R」「Y2 25MHz (CL 18pF), R60 1M across」は、ネットリストと合っている。
