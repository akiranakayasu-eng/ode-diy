# ode_main rev B ケース寸法モデル v3 変更点の別スレッドチェック（2026-11-23）

## 結論

**高 0・中 1・低 1。** 左右の反転（v2 の中 1）は直った。前から見て左から XLR｜RJ45｜USB-C で、アンテナは後ろの右になり、M3 穴・モジュール・アンテナ・J6・天板の JST も同じ向きで反転されている。天板の LED と JST の重なり（v2 の低 1）も直った。ただし、前板の穴の元になるコネクタの位置が PCB 4 版と合っていない（中 1: RJ45 が 4.4mm、XLR が 4.0mm ずれる）。これは v2 からあったもので、v2 のチェックで見落とした。成果物には手を入れていない。

対象: `case/case_model.py`・`ode_revB_case.html`・`case_v3_確認図.png`（05:00 の版）、`ode_main_revB.kicad_pcb`（04:20 の版、PCB 4 版）。PCB の座標は kicad/kicad:10.0 の docker で pcbnew から読んだ（KiCad の上面図の左上が原点、mm）。範囲は v2 の中 1・低 1 に関わる所。中 2（アンテナの横・下の空き）は範囲の外。

出典: ESP32-S3-WROOM-1 データシート（7.1 外形 18.0 × 25.5mm、7.2 推奨ランド図 Figure 10「Antenna Area 6」）、PCB 4 版の各フットプリントの F.Fab（部品の外形線）。

## v2 の中 1（左右の反転）

- 直し方: `PX(x) = X0 + 76 − x` で PCB の x を反転し、y はそのまま。KiCad の上面図（前の辺が上）を 180° 回すと「前が下」の実物の上から見た図になり、このとき x だけが反転し、y（奥へ）は変わらない。式は正しい。
- 反転を通しているもの: 四隅の穴（本体・底板・天板・スペーサー）、モジュール、アンテナ、アンテナの後ろの空きの箱、W5500、ADM2587E、本体の J6、天板の JST、コネクタ 3 つと前板の穴。PCB の座標のまま残っているものは無い。天板の LED・ボタン・リセット穴はケースの座標で置いた目安で、反転は要らない。
- 照合（前から見た x、本体の左端からの距離 = 76 − PCB の x）:

| 部品 | PCB 4 版の x | 実物の x（76 − x） | v3 のモデル |
|---|---|---|---|
| U1 モジュール | 1.55〜19.55 | 56.45〜74.45（右） | 56.5〜74.5 ✓ |
| アンテナ部（DS 図 10、6mm） | 同上、y 84〜90 | 右後ろ | 右後ろ ✓ |
| H1 | 3.55 | 72.45 | 72.5 ✓ |
| H2・H3 | 72.55 | 3.45 | 3.5 ✓ |
| H4 | 49.55 | 26.45 | 26.5 ✓ |
| J6（本体と天板の裏） | 29.08〜48.02 | 27.98〜46.92 | 28.0〜47.0 ✓ |
| J1 USB-C（F.Fab 4.08〜13.02） | 中心 8.55 | 67.45 | 67.5 ✓ |

- 確認図: 上から（前が下）で左から XLR・RJ45・USB-C、モジュールは右後ろ。前からの図も同じ並び。HTML の「アンテナは後ろの右の角」「アンテナの右の側板までは約 4.5mm」も合っている。
- 結果: **直った**。

## v2 の低 1（天板の LED と JST）

- LED の y を Y0 + 70 から Y0 + 58 へ。天板の JST（裏）は y Y0 + 68.8〜74.3 なので、LED（y ± 0.6）とは 10.2mm 離れた。ボタン（± 3）とリセット穴も同じ y で、JST から 7.8mm 以上離れている。
- 天板のねじ（M3、皿の半径 3 程度）との間: x = X0 + 10 の LED と H2（X0 + 3.5、Y0 + 58.0）の中心の間は 6.5mm で、LED の端まで 5.5mm。約 2.5mm 空く。リセット穴と H1（X0 + 72.5、Y0 + 59.5）は 8.6mm。
- 結果: **直った**。

## 中

### 中 1　前板の穴の元になる RJ45 と XLR の位置が PCB 4 版と 4mm ずれている（v2 からあった）

- モデルのコネクタの x は「rev A の位置から 160 を引いた値」で、RJ45 = 32.5、XLR = 55.5。これは PCB 4 版のフットプリントの原点（J5 は R1 ピン 32.55、J11 は 1 番ピン 55.55）と同じ値で、部品の本体の中心ではない。
- PCB 4 版の F.Fab の本体の外形:
  - J5 RJMG1BD3B8K1ANR: x 20.23〜35.98（幅 15.75）→ **中心 28.1**。モデルは 32.5 を中心に幅 16（24.5〜40.5）なので、**4.4mm ずれる**。前板の穴（± 0.5mm）は 24.0〜41.0 になり、本体の 20.2〜24.0 の所が板に当たる。
  - J11 NC3FAH（90°）: 前のつば x 46.81〜72.21（幅 25.4）→ **中心 59.5**。モデルは 55.5 なので、**4.0mm ずれる**。丸穴（半径 11.5）と金具の切り欠きが、本体の筒の位置と合わない。
  - J1 USB-C: F.Fab の中心 8.55、モデル 8.5。合っている。
- 実物の x（前から見て本体の左端から）に直すと、RJ45 は 76 − 28.1 = 47.9、XLR は 76 − 59.5 = 16.5 になる（モデルは今 43.5・20.5）。
- このまま前板の穴を作ると、RJ45 と XLR が前板に入らない。
- 案: `CONN` の x を F.Fab の本体の中心（RJ45 28.1、XLR 59.5）に直し、確認図で前板の穴がコネクタの本体と重なるのを確かめる。RJ45 の幅も F.Fab の 15.75 に合わせるとよい。

## 低

### 低 1　「本体の左前の角が原点」は実物では右前の角

- case_model.py の HOLES のコメントと HTML の表の見出しは「本体の左前の角が原点」としている。穴の値は KiCad の座標（PCB 4 版）なので、原点は上面図の左上で、実物を前から見ると**右前**の角になる。モデルの中では PX() で正しく反転しているので形は合っているが、値を読んで穴をあける人が取り違えやすい。
- 案: 「KiCad の座標（前から見て右前の角が原点、x は左へ）」と書く。

## 範囲の外で気づいたこと

- RJ45 の F.Fab の前の辺は基板の端から 0.5mm 内側（y 0.5）で、モデルは 2.0mm 外へ出している（protrude 2.0）。前板の穴の形には影響しないが、奥行きの向きで見ると実物とは合わない。

## 見落としの原因と防止

- 原因: v2 のチェックで、コネクタの x をモデルの定数どうしでしか見ず、PCB のフットプリントの本体の中心（F.Fab）と照合しなかった。
- 防止: ケースの穴は、フットプリントの原点ではなく F.Fab の本体の外形と照合する、をメモリ（ode-revB-checks.md）に入れた。
