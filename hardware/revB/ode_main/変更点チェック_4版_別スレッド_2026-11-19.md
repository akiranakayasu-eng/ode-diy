# ode_main rev B 回路図 4 版の変更点チェック（2026-11-19、別スレッド）

## 結論

**高 0・中 0・低 1、未確認 3。** 3 版の変更点チェックの指摘（低 1〜3）は 3 件とも直っている。直したことで出た新しい問題は見つからなかった。

F1（PICOSMDC110S-2）の秋月のページが今回は読めた（ブラウザと同じ User-Agent を付けると 200）。定格は秋月の表記・Littelfuse の SCD28326 rev A とも 6V・保持 1.1A（25℃）・トリップ 2.2A。外形は 2.00〜2.20 × 1.30〜1.50 mm で、0805（2012）の大きさにほぼ収まる。ただし保持電流は温度で下がる（60℃で 0.8A）ので、5V の合計電流と比べるのが低 1。推奨ランドはこの資料に無く未確認。

照合のしかた: netlist.net を自分のスクリプト（S 式を読んで部品ごとの両端のネットを出す）で読み、4 版で変えた C74〜C77 と、そのまわり（R4・R5・U5・R80・R81・R1・R2・J1・J6）を書き出して出典の図と並べた。設計ガイドの USB RC の図は元の PNG、WROOM-1 データシートの図 7 は 250dpi、F1 の SCD は 200dpi、回路図の PDF は 300dpi で変えた所を切り出して、どれも画像で見た。設計側の verify.txt・構成案・メモの結論は使っていない。

ほかに変わった所が無いかの見方: 4 版は 353 ピン / 100 部品 / 103 ネット（netlist.net）。3 版も 353 ピン（3 版チェックの記録）で、4 版は部品の追加・削除なし。3 版チェックに書かれた R60・R62・R82・J4・R80・R81 のネットは 4 版でも同じ。3 版の netlist.net そのものは残っていないので、全ネットの突き合わせはしていない（未確認 3）。

## 指摘

### 低

**低 1. F1 の保持電流は 60℃で 0.8A に下がる。5V の合計電流とケースの中の温度で余裕を確かめたい。**（4 版で変えた所ではない。今回初めて定格が読めたので書く）
- [F] TABLE II: 保持／トリップ 0℃ 1.30／2.50A、25℃ 1.10／2.20A、60℃ 0.80／1.60A。8A で 0.2 秒以内にトリップ。抵抗 0.05〜0.17Ω（1 時間後の最大）。定格電圧 6.0VDC、遮断電流 40A。
- F1 の後ろ（VBUS_F → Q1 → +5V）には U6 MCP1826（3.3V の LDO、ESP32-S3 と W5500 ほか）、U11（ADM2587E の VCC 2・8 番）、U7・U9 の VCC がつながる。U11 と 3.3V 側の電流の数字はこのチェックの出典に無く、合計は未確認。
- 合計が 0.8A より十分小さければ問題ない。ケースの中が高くなる（README の残りの確認 1 で LDO の発熱が 1W 近く）なら、F1 を LDO から離して置くか、1 つ上の保持電流の品を考える。PCB の配置で見る点。
- 抵抗 0.17Ω のとき、0.5A で 85mV 落ちる（計算）。

## 問題なしと確かめた所（変えた所とそのまわり）

- C74〜C77 はどれも 2 端子が別々のネットにつながる。C76・C77 は値 DNP。フットプリントは 4 個とも C_0805_2012Metric_Pad1.18x1.45mm_HandSolder で、ほかのコンデンサと同じ。
- C76・C77 を移したことで、USB_DP・USB_DM のネットに U5（USBLC6-2SC6）の I/O ピン（1・6 と 3・4）、J1 の A・B 両面のピンがそのまま残っている。ESD の保護と D+／D− の割り当ては変わっていない。
- CC の時定数: 22k × 100nF ＝ 2.2ms（計算）。CC の電圧はつないだときと充電器の表示が変わるときにしか動かないので、ADC の読みに差し支えない見込み。[H] Power-Up Glitches で GPIO1・GPIO2 は Low 60µs。そのあと C74・C75 が 22k を通して充電されるあいだ（数 ms）、CC から見ると Rd 5.1k に 22k が並ぶ形になる（5.1k ∥ 22k ≈ 4.1k、計算）。10nF のときより長くなるが、電源が入った直後だけの短い間。
- 回路図の注記「R80/R81 22k + C74/C75 100n」「C76/C77 USB caps DNP, connector side of R4/R5」はネットリストと合っている。
- F1 の外形: [F] TABLE I は A（長さ）2.00〜2.20、C（幅）1.30〜1.50、B（高さ）0.80〜1.20、D（電極の長さ）0.25〜0.75 mm。秋月の表記 2.2×1.5×1.2 mm と合う。フットプリント Fuse_0805_2012Metric_Pad1.15x1.40mm_HandSolder の 0805 の大きさにほぼ合う（幅は最大 1.5mm で 0805 の 1.25mm より少し広い）。
- F1 の定格電圧 6.0VDC は USB の 5V より上。USB の VBUS の上限（規格の数字）は今回の出典に無く未確認。
- ERC 0（erc.rpt、2026-11-19 01:37）。

## 未確認（このチェックで確かめられなかった所）

1. **F1 の推奨ランド。** SCD28326 に推奨ランドの図が無い（参照文書 PS300 にあるかもしれないが読んでいない）。Fuse_0805 のパッドの位置・大きさがメーカーの推奨に合うかは未確認。
2. **5V の合計電流。** U11（ADM2587E）・U6 の負荷・LED の電流は今回の出典に無い。低 1 の判断に要る。
3. **3 版とのネットの全部の突き合わせ。** 3 版の netlist.net が残っていないので、ピン数（353 → 353）と 3 版チェックに書かれたネットで見ただけ。
