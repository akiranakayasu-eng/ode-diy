# ode_main rev B 電流の見積もり（2026-11-23、作ったスレッドでの見積もり）

印: 【確】データシートで確かめた、【プ】このプロジェクトの過去の資料、【未】確かめていない

## 結論

- 5V の合計は **ピークで約 0.65A、ふだん約 0.4A**。F1（PICOSMDC110S-2）の保持電流は 25℃ 1.1A、60℃ 0.8A【確: 秋月 113955 の表、4 版チェック】なので、60℃ でもピークより上。ただし余裕は 0.15A ほどなので、**PCB で F1 を LDO（U6）から離して置く**。
- U6 MCP1826（5V→3.3V LDO）の損失は **ピーク約 0.85W、ふだん約 0.4W**。SOT-223 のタブに表裏の銅を広く取る前提。θJA は Microchip のデータシートが作業環境から読めず【未】。
- 部品は替えない（LDO のまま）。θJA を確かめて足りなければ、降圧（DC-DC）に替える案を出す。

## U6 の発熱

- 損失 = (5.0 − 3.3)V × 3.3V 側の電流 → ピーク 0.85W、ふだん 0.43〜0.51W。
- ケースの中が 40℃ のとき、θJA が 50℃/W なら ピーク 82℃・ふだん 62℃。θJA の実際の値（SOT-223、基板の銅の面積による）は【未】。
- Wi-Fi の送信は短い間欠なので、ピークの 0.85W が続くことはない見込み【未】。

## PCB で行うこと

1. U6 のタブ（3.3V 出力）に表裏の銅を広く取り、ビアでつなぐ。
2. F1 は USB-C の近く、U6 からできるだけ離す（F1 の保持電流は温度で下がるため）。
3. ESP32-S3 のアンテナから U6 と F1 を離す（熱と、ESP32 モジュールの使用温度 65℃ のため）。
