# ode_main rev B PCB 4 版 変更点の別スレッドチェック（2026-11-23）

## 結論

**高 0・中 0・低 3。** (1) 外層の GND ベタに、細い切れ端やビアの少ない長い切れ端は残っていない。(2) C74・C75 の GND は、裏の線とビア 2 本で In1 につながっている。(3) SPI と UART の配線は全部つながっていて、長さも W5500 の SPI の速さに対して問題ない。ただし、水晶の下を通る線・R76 の位置・UART の線の道筋で、設計ガイドに沿わない所が 3 点ある（低 1〜3）。成果物には手を入れていない。

対象: `ode_main_revB.kicad_pcb`（2026-11-23 04:20 の版）、`render_top.png`・`render_bottom.png`。範囲は依頼の (1)〜(3)。測り方はこれまでと同じ（kicad/kicad:10.0 の docker でベタを塗り直し、shapely で測った）。座標は基板の左上を原点とする mm。

出典: ESP32-S3 Hardware Design Guidelines（1.4.3 水晶、1.4.5、1.4.6 UART、1.4.7 アンテナ）、W5500 データシート v1.1.0（1 章「SPI ... 80 MHz」、ピン表 30・31 番 XI/XO）。

## (2) U1 の下の裏の C74・C75 の GND

- C74.2 (5.04, 80.0) と C75.2 (5.04, 82.4) は、B.Cu の 0.4mm の線でつながっている。間のビア (5.04, 81.2) で In1 へ。さらに C74.2 から 0.2mm の線で、ビア (5.04, 78.8) にもつながる。GND へのビアは 2 本で、どちらもパッドから 1.2mm 以内。ADC のフィルタのコンデンサ（100n）としては十分に短い。
- CC 側: R80/R81（9.0 / 7.0、80.0 / 82.4）→ C74.1/C75.1 (2.96) → U1.39・38 (1.75, 81.24 / 79.97)。部品はモジュールの下の裏で、U1 のピンのすぐ裏。
- 結果: **問題なし**。

## (3) SPI と UART の配線

### SPI（U3 32〜37 番 ↔ U1 17〜22 番）

| ネット | 長さ | 層 | ビア | 道筋 |
|---|---|---|---|---|
| /ETH_CS_N | 56.5mm | F 9・B 3 | 5 | U1.18 → B.Cu x = 14 → F.Cu y = 57.5 → B.Cu x = 36.5 → U3.32（R66 プルアップ経由） |
| /ETH_SCLK＋/ETH_SCLK_W | 34.5＋14.0mm | F・B | 2＋2 | U1.20 → F.Cu → B.Cu x = 20.75 → F.Cu y = 50.5 → R76 (32.5, 49) → B.Cu x = 31.25 → U3.33 |
| /ETH_MISO | 50.5mm | F 4・B 3 | 2 | U3.34 → B.Cu x = 28.75〜29.0（y 36〜62）→ F.Cu y = 62 → U1.21 |
| /ETH_MOSI | 50.2mm | F 3・B 6 | 4 | U1.19 → B.Cu x = 12.75 → F.Cu y = 58 → B.Cu x = 31 → U3.35 |
| /ETH_INT_N | 62.2mm | F 8・B 2 | 4 | U3.36 → F → B.Cu x = 32.5 → F.Cu y = 58.75〜60 → B.Cu x = 8.75 → U1.22（R65 プルアップ経由） |
| /ETH_RST_N | 50.5mm | F 6・B 1 | 2 | U1.17 → F.Cu y = 64 → B.Cu x = 31.75 → U3.37（R64 プルアップ経由） |

- パッドのネット: U1.17 RST、18 CS、19 MOSI、20 SCLK、21 MISO、22 INT（モジュール DS 図 3 の IO9〜IO14）。U3.32 SCSn、33 SCLK、34 MISO、35 MOSI、36 INTn、37 RSTn（W5500 DS ピン表）。プルアップ R64〜R66 も含めて合っている。
- 長さは 35〜62mm で、伝わる時間は 0.2〜0.4ns 程度。W5500 の SPI の上限 80MHz（周期 12.5ns）に比べて十分に短く、タイミングの問題にはならない。B.Cu の区間は In2（+3V3）が隣の面になる。
- MOSI と MISO の長さの差は 0.3mm で、そろっている。

## 低

1. **W5500 の水晶 Y2 の真下を SPI の線が通る**: /ETH_MISO の B.Cu（x 28.7〜29.1、y 35.9〜62.1）が、Y2（x 26.6〜30.2、y 42.4〜46.6）の真下を通っている。/ETH_SCLK_W の B.Cu（x 31.2〜31.3、y 38.4〜47.3）も XO の直列の R62（x 30.6〜32.6、y 42.1〜45.9）の真下を通り、/ETH_MOSI（x 30.7〜31.3）は Y2 から約 0.5mm の所を通る。設計ガイド 1.4.3（ESP32-S3 の水晶の項）は「Do not route high-frequency digital signal traces under the crystal. It is best not to route any signal trace under the crystal.」としている。この基板では、F.Cu の水晶と B.Cu の線の間に In1（GND）と In2（+3V3）の 2 枚の面があるので、結合は小さいと見る。それでも、Y2 と R60・R62 の下を避けて、x = 26 より左か x = 33 より右を通すとガイドに沿う。
2. **SCLK の直列の R76 が W5500 側にある**: R76（0Ω、C69 DNP と組）は U3.33 から約 12mm、U1.20 から約 27mm の所にある（線の長さでは U1 側 34.5mm、U3 側 14.0mm）。ダンピングの抵抗として使う（0Ω を数十 Ω に替える）なら、出す側（ESP32 の 20 番）の近くの方が効く。設計ガイド 1.4.5 も、SPI の直列の部品はチップの近くに置くとしている（フラッシュの項）。今は 0Ω なので動作には影響しない。
3. **UART の 2 本がモジュールの下をアンテナと平行に約 16mm 走る**: U1.36・37 は左の列（給電点の側）で、アンテナ部（y ≥ 84）から 5〜6mm の所にある。そこから F.Cu を、モジュールの下で y = 77.2〜78.6 のまま右へ 16〜17mm 引いている。設計ガイド 1.4.6 は「UART signal lines ... must be as far away from the antenna as possible」「The UART trace should be surrounded by ground copper and ground vias stitching」としている。ピンから −y 方向（アンテナと逆）へすぐ離すか、ピンのすぐ横で裏へ落として離すとよい。もう 1 点、R77 は U1.37 から線で 38mm 離れている（ガイド 1.4.6「series resistor on the U0TXD trace needs to be placed close to the chip side」）。これは 2 版のチェックで書いた点が残っているもの。ログ用で低速なので、実害は小さい。
