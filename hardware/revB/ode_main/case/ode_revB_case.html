ODE rev B ケース 寸法モデル v5（本体 PCB 4 版に合わせた。アンテナの横と下に窓）

底板・本体・天板を本体の 4 つの M3 穴のスペーサーで重ね、側板 4 枚を上下のつめで挟み込む案。ドラッグで回転、ピンチ・ホイールで拡大。

色: 濃い緑 = 底板・天板、明るい緑 = 本体、半透明の緑 = 側板、白い柱 = スペーサー、黒 = XLR、銀 = RJ45・USB-C、赤 = 天板の LED。灰色 = ESP32-S3 モジュール、赤い帯 = アンテナ部（基板の外へ 6mm）、半透明の青 = アンテナの後ろ 15mm の空き。IC や JST は位置の目安。
