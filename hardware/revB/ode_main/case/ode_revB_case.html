ODE rev B ケース 寸法モデル v1

底板・本体・天板を四隅の M3 スペーサーで重ね、側板 4 枚を上下のつめで挟み込む案。ドラッグで回転、ピンチ・ホイールで拡大。

色: 濃い緑 = 底板・天板、明るい緑 = 本体、半透明の緑 = 側板、白い柱 = スペーサー、黒 = XLR、銀 = RJ45・USB-C、赤 = 天板の LED。IC や JST は位置の目安。
