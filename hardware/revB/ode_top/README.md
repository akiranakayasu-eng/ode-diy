天板 = ケースの上の板そのもの（FR-4 1.6mm、2 層）。四隅の M3 スペーサーで本体の上 35mm に留め、側板のつめを長円の穴に差す。ケースの寸法は `../ode_main/case/case_model.py`（v5）。

## J1 とケーブル

ケーブルは JST PH 8P の両端ハウジング、n 番どうし（線 n がハウジングの n 番どうしをつなぐ）。ハウジングの n 番はヘッダーの n 番に入るので、電気的には J1.n = J6.n になる。並びは J6 と同じ。

| J1・J6 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| ネット | +3V3 | GND | EN_PANEL | BTN_LOCK | LED_LAN | LED_DMX | LED_LOCK | 予備 |

- J1 は裏で、J1.n が J6.n の真上に来る向き（J6 を並びの軸のまわりに裏返した向き）。本体の広い側（ロックの側）は J6 と逆の前を向く。このため、本体の前後の位置は J6 の真上から 0.7mm ずれる（`verify_pcb.txt` の参考の行）。
- 長さは本体の上面から天板の下まで約 35mm、コネクタの高さを引いて 50mm 前後のケーブルを曲げて入れる。

上から見た図で、前（コネクタの面）が画面の下。x はケースの x と同じ（前から見て右へ）なので、表の文字は前から読める。本体 PCB の点 (xm, ym) は天板では (82.6 − xm, 108.6 − ym)。

- 外形 89.2 × 112.7、角 R2。M3 穴 (79.1, 49.1) (10.1, 50.6) (10.1, 28.1) (33.1, 28.1)（本体の穴の真上）。
- 側板のつめの穴 8 つ: 長さ 12.0・幅 1.8 の長円（10.2 × 1.8 の長方形が入る。加工の丸みでつめの角が当たらないように端を半円にした）。中心は `verify_pcb.txt`。

## 部品

前から見て左から DMX｜LAN｜LOCK（LED）｜LOCK｜RESET（ボタン）｜PWR（LED）。PWR は USB-C の上、DMX は XLR の側。

| 部品番号 | シルク | 品 | 購入先 | 電流 |
|---|---|---|---|---|
| D1 | PWR | 黄緑 2012 OSG80805C1C（VF 2.0V） | 秋月 106421 | (3.3−2.0)/330 = 3.9mA |
| D2 | LAN | 黄緑 2012 OSG80805C1C | 秋月 106421 | (3.3−2.0)/(220+100) = 4.1mA（本体 R84 100Ω も通る） |
| D3 | DMX | 黄 2012 OSY50805C1C（VF 2.1V） | 秋月 106420 | (3.3−2.1)/(680+100) = 1.5mA（本体 R85） |
| D4 | LOCK | 赤 2012 OSR50805C1C（VF 2.0V） | 秋月 106419 | (3.3−2.0)/(680+100) = 1.7mA（本体 R86） |
| R1 / R2 / R3・R4 | | 330Ω / 220Ω / 680Ω 0805 | | |
| SW1 | LOCK | TL3342F160QG/TR（rev A で買ったものと同じ） | Digi-Key EG2531CT-ND | |
| SW2 | RESET | TL3342F160QG/TR | Digi-Key EG2531CT-ND | |
| J1 | | JST B8B-PH-K-S（裏） | | |
| ケーブル | | JST PH 8P の両端ケーブル、n 番どうし、50mm 前後。作るなら ハウジング PHR-8 × 2・コンタクト SPH-002T-P0.5L × 16（秋月で扱う品、電線 AWG 28〜24）・電線 × 8 | | |

- J1 の末尾 -S とケーブルの部品の品番は、JST のデータシートが作業環境から読めず確かめていない。
- VF は秋月の商品ページの値（11/23 に在庫ありを確認）。3.3V で点けるので VF 3V 級（純緑・青・白）は使わない。明るさ（20mA の typ × 電流の比）: 黄緑 約 4〜7mcd、黄 約 8mcd、赤 約 13mcd。1 版（黄緑 約 3mcd）より近づけた。組んでそろわなければ R を変える。
- 回路図 1 版で書いた「RESET はクリップで押す」はやめた。表に付けたボタンは指で押せる。天板の表だけでは、穴の奥に沈めたボタンを作れないため。本体にも RESET（本体 SW1）がある。

## 配線

裏: J1 から前へ下ろし、部品の手前でビアで表へ（LED_DMX・LED_LAN・+3V3・EN_PANEL・BTN_LOCK）。LED_LOCK は裏の線をまたぐので表だけで引いた。表と裏は GND ベタ（最小幅 0.5、サーマルのスポーク 0.5）、GND のつなぎビア 78 本（10mm おき）。線 0.3mm、ビア φ0.6 / 0.3。
