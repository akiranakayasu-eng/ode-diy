## (1) J1 と J6 のピンとネット、裏面での向き

ネット（天板 netlist.net と本体 netlist.net）:

| ピン | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 本体 J6 | +3V3 | GND | EN_PANEL | BTN_LOCK | LED_LAN | LED_DMX | LED_LOCK | 未接続 |
| 天板 J1 | +3V3 | GND | EN_PANEL | BTN_LOCK | LED_LAN | LED_DMX | LED_LOCK | 未接続 |

- 天板側の行き先: J1.1 → R1 → D1（PWR）。J1.3 → SW2 → GND。J1.4 → SW1 → GND。J1.5 → R2 → D2。J1.6 → R3 → D3。J1.7 → R4 → D4。本体側は J6.5〜7 が R84〜R86（100Ω）を通って U1 の 4〜6 番、J6.3 が R79 を通って EN、J6.4 が R83 を通って U1 の 7 番。
- n 番どうしのケーブルでは、電気的に J1.n = J6.n になる。8 本とも同じネット。✓

位置（pcbnew の絶対座標）:
- 本体 J6: 表、0°、パッド n は (142 + 2(n−1), 134.0)。
- 天板 J1: 裏（B.Cu）、180°、パッド n は (155 − 2(n−1), 86.25)。
- 2 枚の対応は、M3 穴 4 つから自分で出した。天板 = (297 − x本体, 220.25 − y本体)。これは上から見て 180° の回転で、鏡像ではない。穴の並びが非対称なので、この式しか合わない。4 穴とも一致した。
- この式で J6 の n 番を天板に写すと (155 − 2(n−1), 86.25) になり、J1 の n 番とぴったり重なる。✓
- 向き: J6 の本体（F.Fab・クーティヤード）はピンの列から本体の後ろへ広く出ている。J1 は天板の前へ広く出ている。J1 は、J6 を「並びの軸のまわり」に 180° 回した形になっている。ハウジングも同じ回し方で上下に向かい合う。n 番の線はまっすぐ上下に渡り、ケーブルはねじれない。✓
- この結論は、KiCad のフットプリントの 1 番が JST の 1 番と合っているかどうかに左右されない。J1 と J6 は同じフットプリントなので、ずれがあっても両方に同じようにかかる。
- 裏の確認図（render_bottom.png）では、四角のパッド（1 番）が、裏から見て左にある。表から見た x 155 の位置で、合っている。裏のシルクに「pin n to pin n, J1.1 = +3V3」とある。
- `verify_pcb.py` の照合は「J1.n と J6.n のネットが同じ」と「真下が J6.n」の両方を見ていて、NG 0。上の自分の計算と同じ。

## 低

### 低 1　Value に品番と用途の名前が混ざっている

- 「OSG80805C1C (PWR)」「TL3342F160QG (LOCK)」のように、Value に品番と用途が一緒に入っている。
- KiCad の部品表で Value ごとにまとめると、同じ品番の D1 と D2、SW1 と SW2 が別の行に分かれる。Value をそのまま購入先の検索に貼っても、そのままでは見つからない。
- 案: Value は品番だけにする（または品番を MPN の欄に分ける）。用途の名前はシルクと README に任せる。

### 低 2　J1 の品番の書き方と、ケーブル・ハウジングが部品表に無い

- JST の注文用の品番には、ふつう末尾に「-S」などが付く（例: B8B-PH-K-S）。JST の DS が読めず、**未確認**。発注の前に購入先のページで、注文できる品番を確かめるとよい。
- README の部品表に、ケーブル（または PHR-8 ハウジング 2 個と SPH 系の端子）が無い。このボードは「n 番どうし」のケーブルが前提で、市販の両端ケーブルには逆向き（1 → 8）のものもある。逆向きを使うと 1 版の高 1 と同じ症状になる（天板に +3V3 が来ない、EN が中途の電圧など）。
- 案: README の部品表に、ケーブルの品（または自作ならハウジングと端子）と「n 番どうし（同じ向き）」を 1 行足す。

### 低 3　SW の Value が rev A で買った品番と末尾が違う

- rev A で買ったのは TL3342F160QG/TR（テープ巻き、Digi-Key EG2531CT-ND）。今の Value は TL3342F160QG で、「/TR」が無い。同じ部品の包装違いと思われるが、E-Switch・Digi-Key のページが読めず**未確認**。README の「rev A と同じ」に合わせるなら、Value（または MPN）も /TR に合わせるとよい。
