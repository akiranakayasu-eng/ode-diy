# ode_top rev B 天板 回路図 7 版・PCB 1 版の別スレッドチェック（2026-11-23）

## 結論

**高 1・中 0・低 3。**
- **高 1:** J1 のピンの並びが、ストレートのケーブル（n 番 → n 番）と合わない。このまま組むと、天板に +3V3 が来ない。本体の LED_LOCK の出力が GND に、EN（リセット）が天板の LED につながる。
- 外形・つめの穴・M3 穴は、ケースモデル v5 と合っている。
- LED の電流は 1.5〜1.9mA で、定格の内側。
- スイッチのフットプリントは本体・rev A と同じもので、DRC は 0。

成果物には手を入れていない。

対象: `ode_top_revB.kicad_sch`・`.kicad_pcb`・`netlist.net`・`scripts/gen_pcb.py`（05:23 の版）。照合先は本体 `ode_main_revB.kicad_pcb`（PCB 4 版、04:20）と `netlist.net`、`case/case_model.py`（v5）。座標は kicad/kicad:10.0 の docker で pcbnew から読んだ。DRC も同じ docker で回し直した（`--schematic-parity --severity-all`）。

## (1) J1 と本体 J6 のピンの対応

本体 J6（表、0°）と天板 J1（裏、0°）のパッドとネット:

| 位置（前から見て左→右） | 本体 J6 | ネット | 真上の天板 J1 | ネット |
|---|---|---|---|---|
| ケース x 37.1 | 8 | 未接続 | 1 | 未接続 |
| 39.1 | 7 | LED_LOCK | 2 | LED_LOCK |
| 41.1 | 6 | LED_DMX | 3 | LED_DMX |
| 43.1 | 5 | LED_LAN | 4 | LED_LAN |
| 45.1 | 4 | BTN_LOCK | 5 | BTN_LOCK |
| 47.1 | 3 | EN_PANEL | 6 | EN_PANEL |
| 49.1 | 2 | GND | 7 | GND |
| 51.1 | 1 | +3V3 | 8 | +3V3 |

- 位置の照合: J1 の 1 番 (37.10, 37.60) は、本体の座標で (82.6 − 37.10, 108.6 − 37.60) = (45.5, 71.0) で、J6 の 8 番 (45.5, 71.0) の真上。ケースの座標では、どちらも x 37.1・y 75.1。8 本とも同じ。
- **真上のピンどうしは同じ信号になっている。ただし、J1 の n 番は J6 の (9 − n) 番の信号。**

### 高 1　ストレートのケーブル（n 番 → n 番）だと、J1 の n 番は J6 の n 番につながり、信号が全部ずれる

- ケーブルの線 n は、片側のハウジングの n 番と、もう片側のハウジングの n 番をつなぐ。ハウジングの n 番は、差した相手のヘッダーの n 番に入る。だから n 番 → n 番のケーブルでは、ケーブルがどう曲がっても、**電気的には J1 の n 番 = J6 の n 番**になる。「真上にあるピン」どうしがつながるのではない。
- 今の J1 の並びで n 番 → n 番のケーブルをつなぐと、次のようになる:

| J6 | 信号 | → J1 | J1 側の行き先 | 起きること |
|---|---|---|---|---|
| 1 | +3V3 | 1 | 未接続 | 天板に電源が来ない |
| 2 | GND | 2 | R4 → D4（LOCK の LED）の陽極 | LOCK の LED が点かない |
| 3 | EN_PANEL（R79 1k → EN） | 3 | R3 680 → D3 → GND | EN が R31 10k と R79 1k＋R3 680＋LED で分圧され、約 1.9V。ESP32-S3 の EN が中途の電圧になり、起動しないおそれ |
| 4 | BTN_LOCK | 4 | R2 → D2 → GND | ボタンの入力が LED に引かれる |
| 5 | LED_LAN | 5 | SW1 → GND | SW1 を押すと IO4 の出力が R84 100Ω で GND にショート |
| 6 | LED_DMX | 6 | SW2 → GND | SW2 を押すと IO5 が同じく GND にショート |
| 7 | LED_LOCK | 7 | GND | IO6 の出力が R86 100Ω だけで GND に。H のとき 33mA |
| 8 | 未接続 | 8 | +3V3 | — |

- 本体の側: LED_LAN = U1.4（IO4）→ R84 100Ω、LED_DMX = U1.5 → R85 100Ω、LED_LOCK = U1.6 → R86 100Ω、EN_PANEL = R79 1k → EN（R31 10k プルアップ、C33 1µ）、BTN_LOCK = R83 1k → IO7（R87 10k）（本体 netlist.net）。
- 今の並びで正しく動くのは、**逆向きのケーブル（J6 の n 番 → J1 の (9 − n) 番）**を使うときだけ。
- 向きの見立て:
  - 今の J1 は、J6 を「並びに直角の軸のまわり」に裏返した形。上から見て左右が反転し、本体の広い側（フットプリントの溝の印の側）はどちらも後ろを向く。
  - この形で線がねじれずに上下へ渡るのは、逆向きのケーブル。
  - n 番 → n 番のケーブルを使うと、ケーブルを縦の軸のまわりに半回転ねじることになる。

**案（どちらか）**
- **A（勧める）:** J1 のネットを J6 と同じ並びにする（J1.1 = +3V3 … J1.7 = LED_LOCK、J1.8 = 未接続）。そのうえで J1 を裏のまま 180° 回して、J1 の n 番を J6 の n 番の真上に置く。
  - こうすると J1 は J6 を「並びの軸のまわり」に裏返した形になり、n 番 → n 番のケーブルがねじれずに渡る。
  - ロック（本体の広い側）は J6 と逆の前を向く。ハウジングもケーブルの上で同じく逆を向くので、そのまま差さる。
  - 本体の前後の位置が 1.1mm ほど変わる（本体は列から −1.7 / +2.9 で非対称）ので、F.Fab の範囲を J6 の真上に合わせ直す。
- **B:** 今の基板のまま、逆向きのケーブル（1 → 8 番）を使う。部品表とケーブルの図に「逆向き」と書く。ただし、市販の両端ケーブルを取り違えると上の表のとおりになるので、A の方が安全。

- `verify_pcb.txt` の照合は「真下のピンのネットが同じ」を見ているので、この取り違えは見つからない。照合を「J1.n と J6.n のネットが同じ（ケーブルが n → n のとき）」に変えるとよい。

## (3) LED の電流

秋月の商品ページと OSXX0805C1C DS の表（IF = 20mA）:
- OSG80805C1C 黄緑（106421）: VF 2.0（max 2.6）、Iv 20〜35mcd
- OSY50805C1C 黄（106420）: VF 2.1（max 2.6）、Iv 100〜120
- OSR50805C1C 赤（106419）: VF 2.0（max 2.6）、Iv 120〜150
- 3 つとも IF max 30mA、在庫あり（11/23 読んだ時点）。

| LED | 経路 | 電流（VF typ） | VF max 2.6 のとき |
|---|---|---|---|
| D1 PWR 黄緑 | +3V3 → R1 680 | (3.3 − 2.0) / 680 = 1.9mA | 1.0mA |
| D2 LAN 黄緑 | IO4 → R84 100 → R2 680 | 1.3 / 780 = 1.7mA | 0.9mA |
| D3 DMX 黄 | IO5 → R85 100 → R3 680 | 1.2 / 780 = 1.5mA | 0.9mA |
| D4 LOCK 赤 | IO6 → R86 100 → R4 680 | 1.3 / 780 = 1.7mA | 0.9mA |

- どれも定格 30mA のずっと内側で、GPIO の負担も小さい。極性は、DS の外形図の「① − / ② +」と KiCad の LED（1 = K、2 = A）、ネット（D*.1 = GND、D*.2 = R の側）で合っている。
- 3.3V で VF 2.0〜2.1V の色を選んでいるのは正しい（VF 3.3V の緑・青・白では点かない）。

## (4) スイッチのフットプリントと DRC

- SW1（LOCK）・SW2（RESET）は `Button_Switch_SMD:SW_SPST_TL3342`。パッドは 1.7 × 1.0 が 4 つで、(±3.15, ±1.9)。上の 2 つが 1 番、下の 2 つが 2 番。本体 rev B の SW1、rev A の 2 つと同じフットプリント（rev A は組んで動いている）。
- ネット: SW1 は BTN_LOCK と GND、SW2 は EN_PANEL と GND。押したときの電圧は 3.3 × 1k / (10k + 1k) = 0.3V で、EN も IO7 も L になる（本体の R79・R83 1k と R31・R87 10k）。ただしこれは高 1 を直したあとの話。
- DRC: 回し直して、エラー 0・警告 0・未接続 0、回路図との照合 0。drc.txt と同じ。ERC 0（erc.rpt）。
- TL3342 の足の寸法・推奨ランドは、E-Switch の DS が読めず見ていない。

## 低

### 低 1　LED の明るさが 4〜5 倍違う

- 1.5〜1.9mA での明るさは、DS の typ に電流の比をかけて、黄緑 約 3mcd、黄 約 9mcd、赤 約 13mcd。PWR と LAN（黄緑）は DMX・LOCK の 1/3〜1/4。
- VF が max 寄りの個体なら、電流は 1mA 前後まで下がる。
- そろえるなら、R1・R2 を下げる（たとえば 220Ω で約 4mA → 約 7mcd）。

### 低 2　LED の品番が回路図に無い

- D1〜D4 の Value は「PWR・LAN・DMX・LOCK」で、品番（OSG80805C1C など）と購入先は README の表にしかない。R1〜R4 の大きさ・精度、SW の品番（TL3342F160QG）、J1 の品番（B8B-PH-K）も回路図の欄に無い。
- 部品表を回路図から作るときに抜けるので、MPN の欄に入れるとよい。

### 低 3　README の「本体 R85 100Ω も通る」は LAN ではない

- 本体で LAN を通るのは R84、R85 は DMX。3 つの LED（LAN・DMX・LOCK）はどれも 100Ω を通る。電流の値（780Ω で計算）は合っている。

## 確かめていないこと

- JST PH のデータシート（B8B-PH-K の外形・ロックの側、PHR-8）。ロックの側は KiCad のフットプリントの形（列から −1.7 / +2.9 の非対称）でしか見ていない。高 1 の結論は、ロックがどちらの側でも変わらない。
- E-Switch TL3342 のデータシート（足の寸法と、内部でつながっている足の組）。
- 天板の表から見える J1 の足のはんだ（裏付けの通し穴の部品なので、表にはんだが出る）。見た目だけの点。
