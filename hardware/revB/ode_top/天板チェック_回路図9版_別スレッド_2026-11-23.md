## 低

### 低 1　コンタクトの品番 SPH-002T-P0.5S は秋月で売っていない（秋月は P0.5L）

- 秋月で「SPH-002T」を探すと、出てくるのは SPH-002T-P0.5L（112837・112809）と P0.5LC（117163）だけ。P0.5S は無かった。
- DS の P0.5L は AWG 28〜24（0.08〜0.22mm²、被覆の外径 0.8〜1.5mm）。DS の注 2 には「P0.5L は挿抜しやすいように嵌合力を低くしたコンタクト。振動の少ない所で使う。圧着のクリンプハイトが標準品と違う」とある。
- 部品は秋月から買うのが基本なので、そのままだと README と違う型が届く。
- 案（どちらか）:
  - 秋月の P0.5L を使うなら、README を P0.5L（112837）に変え、電線を AWG 28〜26 にする（AWG 30 は P0.5L では範囲外）。箱の中で振動はほぼないので、P0.5L でも困らない。
  - P0.5S を使うなら、Digi-Key などの購入先を README に書く。
- あわせて、README の「J1 の末尾 -S とケーブルの部品の品番は、JST のデータシートが作業環境から読めず確かめていない」は、秋月の PH.pdf で確かめられる（出典として秋月 goodsaffix/PH.pdf を書いておくとよい）。

## 確かめていないこと

- TL3342F160QG/TR の品番の意味と在庫（Digi-Key・E-Switch が読めなかった）。rev A の部品表と同じ品番であることだけを確かめた。
- コンタクトの圧着の工具（DS の表は自動機用のアプリケータだけ）。手で圧着するときの工具は見ていない。
