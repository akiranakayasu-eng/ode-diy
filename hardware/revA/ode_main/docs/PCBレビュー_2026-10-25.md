# ode_main rev A 発注前レビュー（2026-10-25）

## 結論

**発注可（条件つき）**。DRC エラー 0、未接続 0、回路図との不一致 0。
発注前に 1 点だけ、AP7361C-33E（U6）のピン配置を Diodes の公式データシートで確認する（下の「未確認」）。

## 確認した点（問題なし）

### 自動チェック
- ERC 0、ネット照合 0（gen_sch の設計意図と netlist をピン単位で照合）
- DRC: エラー 0、未接続 0、schematic parity 0。警告は 2 種類だけで、どちらも sacn_node と同じ扱い
  - silk_edge_clearance ×4: XLR（NC3FAH）のフットプリントのシルクが前面の基板端にかかる。製造上は切れるだけ
  - lib_footprint_mismatch ×1: U3 の VQFN にサーマルビアを足したため
- verify_pcb: 全パッドのネットと Value がネットリストと一致。SMD パッドの中のビア 0。内層ベタの島は GND / +3V3 / +3V3_ETH / GND_ISO_1 / GND_ISO_2 とも 1 個ずつ
  - 「ベタのパッドにビアが無い」4 件は C109 / C209（1nF 2kV、絶縁帯をまたぐ）。設計どおりで、太い線でビアへつないである

### ピン配置（データシートの標準ピン配置と照合）
- STM32F407VGT6（LQFP-100）: PA11 = 70 / PA12 = 71（USB OTG_FS、DFU）、PE0 = 97 / PE1 = 98（DMX TX1 / TX2）、PD7 = 88（DE）、PC10 = 78 / PC11 = 79（LED）、PD4 = 85（LOCK ボタン）、PA9 = 68 / PA10 = 69（UART）。RMII と HSE は sacn_node_main と同じ（2026-10-20 レビュー済み）
  - DMX の TX は UART ではなく PE0 / PE1 をタイマ起動の DMA で GPIO に書く方式（sacn_node と同じファーム構造）
- USBLC6-2SC6（U5）: 1 / 6 = D+、3 / 4 = D−、2 = GND、5 = VBUS。データシートどおり
- AO3401A（Q1）: 1 = G、2 = S（VBUS_F）、3 = D（+5V）。C2 1µF（S–G）と R3 100k（G–GND）でゆっくり ON する突入電流制限
- 74AHCT1G125（U7 / U8 / U9）: 1 = OE#（GND で常時有効）、2 = A、3 = GND、4 = Y、5 = VCC（+5V）。3.3V 入力を 5V に上げて ADM2587E の TxD / DE へ
- ADM2587E（U11 / U21）: dmx_usb_pro・sacn_node_out8 と同じ周辺。VCC = +5V、~RE を DE とつないで送信専用（RxD は未接続）
- USB-C（J1）: CC1 / CC2 に 5.1k プルダウン（5V シンク）。A1/B12/A12/B1 = GND、A4/B9/A9/B4 = VBUS

### PCB
- 絶縁帯 7.75mm（ポートの間と一次側との間）。4 層ともトラック・ビア・ベタ禁止の区域とカスタム DRC ルール（7.5mm）で確認。帯を渡るのは ADM2587E と C109 / C209 だけ
- 水晶: 25MHz（Y2）の配線長 X25_IN 11.8mm（ビア 2）/ X25_OUT 11.2mm、8MHz（Y1）は sacn_node_main と同じ配置
- パスコンと電源ピンの距離: すべて 6mm 以内（U1 の各電源ピン、U3、U4、U6、U7〜U9）
- シルク: 文字の重なりと、パッドにかかる文字を直した（USB-C 5V、SWD、RESET / LOCK、ISOLATION 2.5kV）。他社の商標は無い

## 注意（発注は可、使い方で気をつけること）

1. **電源は USB-C の AC アダプタ（5V 1.5A 以上を出すもの）を使う**。PD は使わず 5.1k の CC で 5V を受けるだけなので、アダプタが 1.5A / 3A を広告すればその電流まで使える。PC の USB ポート（500mA）では 2 ポートの ADM2587E が満負荷のとき足りないことがある。消費の見積もりは 5V で最大約 0.5A（ADM2587E 2 個で約 0.3A、3.3V 系で約 0.2A）
2. **USB の D+ / D− の配線が長い**（約 10cm、ビア 2〜5 個）。USB-C が左上、MCU が左下にあるため。USB Full Speed（12Mbps、ファーム書き込みの DFU 用）なので実用上は問題ない見込みだが、DFU で書けないときは SWD（J3）で書く
3. PE0 / PE1 での DMX 出力はファームの作りに依存する。UART を使う形に後で変えたい場合は基板の改版が要る
