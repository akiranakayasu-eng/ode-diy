# ode_main rev A 手実装版 実機立ち上げ記録（2026-11-10）

## 結果

DMX 1 系統で手実装した 1 台で、ファームを入れる前の確認がすべて通った。

| 確認 | 結果 |
|---|---|
| 通電前の短絡（C1 VBUS、C3 +5V、C5 +3V3、C105・C107 絶縁側） | すべて短絡なし（C105 は 5.37kΩ） |
| 通電（USB-C 給電） | D4（電源）・D12（絶縁側）点灯 |
| 電圧 | +5V 5.12V（C3）、+3V3 3.275V（C5）、VISO 3.386V（C107） |
| SWD 接続（STLINK-V3SET → J3、STM32CubeProgrammer） | STM32F405xx/F407xx、Device ID 0x413、ターゲット電圧 3.28V、フラッシュ 1MB、中身は空（FF） |
| LAN（ファームなし、ケーブルをつないだだけ） | J5 の LED（緑・オレンジ）点灯。PHY_RST_N は R64 でプルアップ、LED は U3 → R67/R68 → J5 |

## 書き込み環境

- STLINK-V3SET（秋月 114361）本体の 14 ピン CN1 → 付属 ARM10 フラットケーブル → J3（1.27mm 2×5、1 番は基板の左上、切り欠きなし。ケーブルの赤線を 1・2 番側に）。MB1440 は不要。
- 基板は USB-C で給電（ST-LINK は給電しない）。JP1 は開放（BOOT0 は R31 でプルダウン）。
- Mac に STM32CubeProgrammer。

## rev B に回すこと

- F1 のフットプリントを 0805 に。
- シルクの部品番号を各部品のすぐ横に。
- J3 に向きの切り欠きのあるヘッダ（シュラウド付き）を検討。
