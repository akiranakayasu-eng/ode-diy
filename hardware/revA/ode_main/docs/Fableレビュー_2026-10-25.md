## 注意（基板はこのまま。ファームか組み立てで対応）

1. **USB DFU は VBUS 検出なしで動く見込み**。この基板は PA9（OTG_FS_VBUS）を UART TX に使っていて VBUS 検出を付けていない。ST のフォーラムでは F405 で VBUS 検出なしで DFU が動いた報告があり、AN2606 の F40x の表にも VBUS ピンは出てこない。ただし ST の文書で「不要」と明記されたものは見つけられなかった。DFU が立ち上がらないときは J3 の SWD か、J4 の USART1（これも ROM ブートローダ対応）で書く。ファーム側は USB を NOVBUSSENS で使う。
2. **TX1_M / TX2_M（PE0 / PE1）にプルアップが無い**。リセット中は MCU のピンが入力で浮き、74AHCT1G125 の入力が不定になる。DE は 10k プルダウンで L なので DMX 線には出ない（実害なし）。rev B では 10k プルアップ（DMX のアイドルは H）を足すときれい。
3. **取り付け穴が下半分にしかない**（y = 62 / 80.5 の 4 個）。上辺のコネクタは前面パネルで支える前提。XLR（NC3FAH）のフランジ 2 本のネジをパネルに留めれば上辺も固定される。パネル無しで使うときは、XLR 抜き差しで基板がたわむので、ケースの設計で上辺を押さえる。
4. **USB の D+ / D− が長い**（約 10cm、ビア 2〜5 個）。Full Speed（12Mbps）の DFU 用なので動く見込み。
